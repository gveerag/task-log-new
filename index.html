Google Sheet sync

This is the preview. Live sync works in the standalone app file, not here.

Each time you save, edit or delete an entry, the app sends all entries to your Google Sheet.

One-time setup (easier on a computer)
  1. Create a Google Sheet.
  2. Open Extensions, then Apps Script. Delete the sample code and paste the script below.
  3. Tap Deploy, then New deployment, type Web app. Set Execute as: Me and Who has access: Anyone. Deploy and allow access.
  4. Copy the Web app URL and paste it above.
