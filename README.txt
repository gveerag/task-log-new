TASK LOG - install on Android

1. Upload this whole folder to any HTTPS host (GitHub Pages, Netlify Drop, Cloudflare Pages).
2. Open the site's address in Chrome on your phone.
3. Tap the menu (three dots) > Install app (or Add to Home screen).
4. Task Log now opens from its own icon, full screen, and works offline.

Notes:
- Your entries are stored on the phone in that app. They are not shared with the website.
- Open the app once while online so it can save the Excel export library for offline use.
- Google Sheet sync still needs an internet connection.
